# 黄色い椅子 自動生成スクリプトの使い方

ファイル: `amuse_chair.rb`

## 実行方法
1. SketchUpでモデルを開く（新規でも可）
2. メニュー「ウィンドウ > Rubyコンソール」を開く
3. コンソールに次を入力して Enter（パスは保存場所に合わせる）

```
load 'C:/Users/kit-s/Downloads/amuse_chair.rb'
```

4. 「AMuse_黄色い椅子」というグループが作られ、画面が椅子にズームします

## 寸法（寸法図から）
- 全高 790mm
- 座面高さ 520mm、座面 幅280mm × 奥行290mm、厚み30mm
- 脚の広がり（接地面）幅410mm × 奥行430mm

## 写真からの近似
- 脚は外へ広がる先細りの丸脚、足掛けバーは前後左右の4本
- 背もたれはスピンドル4本＋上部の板（少し後傾）。上部の板は、写真に合わせて上縁が緩い弧で両端が丸い形（v3）
- 色はマスタードイエロー（マテリアル「椅子_マスタードイエロー」）
- 座面の角の丸み、脚やバーの接合部の作り込みは簡略化しています

## 注意
- AMuse側ではSketchUp本体で実行確認ができないため、初回は新規ファイルかコピーしたファイルで試してください
- エラーが出たら、Rubyコンソールに表示された文面をそのまま送ってください。その場で直します
- 寸法を変えたい場合は、スクリプト冒頭の CONFIG の数字（mm）を書き換えて再読み込みしてください
